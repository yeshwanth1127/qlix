# Loan approval demo — company brain documents

Upload these files into **AI Brain** (org workspace) as one collection named e.g. **Loan Policies**.

## Suggested collection

| Collection name | Purpose |
|-----------------|--------|
| `Loan Policies` | All demo underwriting + compliance docs below |

## How to ingest

1. Open **AI Brain** in your org workspace.
2. Create collection **Loan Policies** (if needed).
3. Upload each `.md` file, or paste content into **Ingest document**.
4. Wait until documents show **ready** / embeddings complete (refresh status).
5. Run the **Loan Approval Pilot** team with `brain.query` on Calculator and Compliance workers.
