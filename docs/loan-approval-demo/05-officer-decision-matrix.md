# NovaLend — Loan Officer Decision Matrix (Summary for Supervisor)

**Version:** 2026.1  
**Purpose:** Final synthesis guidance for human officer + WhatsApp delivery

## Recommendation codes

| Code | When to use |
|------|-------------|
| APPROVE | All policy pass; docs LOW risk; DTI ≤ 43% verified; compliance APPROVED |
| CONDITIONAL_APPROVE | Credit OK but document/EDD items open; list exact conditions |
| DECLINE | DTI fail, score < 680, sanctions HIT, or unresolvable HIGH doc risk |

## Demo case LA-2026-0847 — expected pattern

Given stated facts (score 712, income ₹12L, debts ₹28k + proposed EMI ₹22.5k):

- **Salary-only DTI** ≈ (28000 + 22500) / 100000 ≈ **50.5%** → **FAIL** vs 43% cap  
- **Without proposed EMI** ≈ 28% → pass component  
- Likely supervisor outcome: **CONDITIONAL_APPROVE** or **DECLINE** depending on whether proposed EMI is included and income verification—not blind APPROVE.

Officer brief must cite:
- Underwriting Standards (DTI 43%)
- Required Documents (ITR missing, stale employer letter)
- Sanctions & EDD (gift transfer)
