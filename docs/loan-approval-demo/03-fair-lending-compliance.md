# NovaLend — Fair Lending & Compliance Policy (Demo)

**Regulatory alignment:** RBI fair practices; internal non-discrimination standard  
**Version:** 2026.1

## Protected characteristics

Decisions must **not** use or proxy:
- Religion, caste, gender, marital status, pregnancy, disability
- Neighborhood ethnicity composition
- Personal relationship status

Permitted factors: income, debts, credit history, collateral (if any), documented fraud signals, sanctions.

## Fair lending review checklist

For each application, Compliance must confirm:
1. Decline/approve reasons are tied to **creditworthiness** or **documented policy**.
2. No adverse action based on name, address locality, or photo ID type alone.
3. **Conditional approval** terms are applied consistently (same doc gaps → same conditions).

## Age eligibility

- Minimum **21** (see Underwriting Standards)
- If applicant under 21 → **BLOCKER: DECLINE**

## Geographic restrictions (demo)

- No lending to sanctioned jurisdictions list (see Sanctions policy)
- Standard India domestic only for this product

## Adverse action communication

If **DECLINE**, officer brief must include:
- Primary numeric reason (DTI, score, missing docs)
- No prohibited-factor language

## Compliance status definitions

| Status | Meaning |
|--------|---------|
| APPROVED | No blockers; fair-lending check pass |
| CONDITIONAL | Blockers none but advisories require officer conditions |
| DECLINED | Blocker present (policy violation, sanctions hit, fair-lending concern) |

## Advisories (examples for demo case)

- Missing ITR FY 2024-25 → ADVISORY: request before final approve
- Unexplained ₹2,40,000 "gift" transfer → ADVISORY: source-of-funds verification
- Stale employer letter → ADVISORY: refresh within 90 days
