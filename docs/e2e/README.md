## Upload Field Support playbook (AI Brain)

1. Org workspace → **AI Brain**.
2. Create collection **`Field Support`**.
3. **Upload** [`field-support-log-review-playbook.md`](./field-support-log-review-playbook.md) or paste its contents into **Ingest document**.
4. Title: **Field Support — Log Review Playbook**.
5. Wait until the document status is **ready** before running the WhatsApp or hybrid E2E test.
