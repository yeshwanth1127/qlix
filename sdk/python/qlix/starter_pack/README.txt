Qlix Agent — quick start
========================

1. Unzip this folder anywhere on your computer.
2. Double-click the "Start Qlix Agent" file in this folder
   (Windows: .bat  |  Mac: .command  |  Linux: .sh).
3. Keep that window open. Return to Qlix in your browser and chat with your agent.

The first launch may take a minute to finish setup.
If asked to install Python, use Python 3.10+ from python.org (check "Add to PATH" on Windows).

API keys (OpenAI, OpenRouter, etc.) are managed by your Qlix server — you do not
need to set them on this computer. Desktop automation (gui_control) and coding
tasks (s3_code_task) also use the Qlix proxy when your agent uses proxy mode.

To stop the agent, close the window or press Ctrl+C.
